# 10. MVP Scope & Cutline

## 10.1 Критерии MVP

MVP должен позволить:
1. Пилотной группе (5-10 человек) работать на одном объекте (СИТИ-4).
2. Ежедневно вводить план-факт через Bot и Mini App.
3. Получать уведомления о назначениях, просрочках, эскалациях.
4. Видеть прогресс в аналитике (сводки, накопления).
5. Импортировать данные из существующих Excel-файлов.
